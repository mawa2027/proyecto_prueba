# Hola Coolify

Proyecto mínimo en Python (Flask) para probar el despliegue en Coolify.

- `app.py`: la aplicación (dos rutas: `/` y `/salud`).
- `requirements.txt`: librerías que necesita.
- `Dockerfile`: instrucciones para armar el contenedor.
- `.env.example`: variables de entorno que se cargan en Coolify.

Puerto de la aplicación: **5000**.
